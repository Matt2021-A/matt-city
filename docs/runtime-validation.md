## Known blockers and warnings

### Dolt-backed rig initialization

Gas City 1.3.4 with the installed Beads 1.1.0 repeatedly failed to initialize a new rig using the managed Dolt backend. A clean retry reproduced the schema migration error associated with `gastownhall/beads#4566`.

The failure was not caused by stale repository state. `gc rig add` recreated the failing store from a clean repository.

Dolt-backed durability remains unvalidated and must not be described as production-ready.

### Beads library and CLI drift

Gas City reported that the standalone `bd` version differed from the Beads library linked into `gc`, despite Homebrew showing Gas City 1.3.4 and Beads 1.1.0. This is treated as a release-build compatibility issue until an aligned release is available.

### File-backend custom types

`gc doctor --fix` could not repair `types.custom` for the Matt City rig under the file backend. The rig store remained accessible and the failure did not block registration. This warning must be re-tested when Gas City and Beads versions are upgraded.

### Local-only event archive

The Gas City JSONL archive currently has no off-box remote. This is acceptable for the Phase 1 lab but not for a durable production service.

### Legacy HQ stores

The city runtime contains Dolt and embedded-Dolt remnants from the initial managed-store setup. They are preserved for diagnosis and must not be deleted until exported or deliberately retired.

## Generated repository artifacts

Rig registration modifies or creates local runtime projections:

- `.beads/`
- `.agents/skills/`
- `.gitignore` rules

Policy:

- `.beads/identity.toml` may be versioned when generated and reviewed.
- Other `.beads` state remains local.
- `.agents/skills` is generated from installed Gas City packs and remains local unless a future review establishes a stable vendoring requirement.
- Hand-authored Matt City agent definitions remain under `city/agents/`.

## Source-of-truth rule

Asana remains the canonical human work and context plane. Gas City is the machine execution plane. GitHub stores versioned implementation and approved artifacts. Runtime-generated local state is not a substitute for any of those systems of record.
