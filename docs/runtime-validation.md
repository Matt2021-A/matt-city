## Known pre-reboot operational issues

### Session snapshot and store-status latency

`gc status` repeatedly timed out while loading the session snapshot after three seconds, then continued with runtime-only status. One isolated status run took more than 30 seconds.

The supervisor HTTP API itself responded quickly during the same investigation. The slow path therefore appeared related to session projection, store reads, or concurrent maintenance activity rather than general API unavailability.

The runtime also showed sustained Dolt and Beads activity from order, wisp, convoy, query, and metrics processes. This remains historical diagnostic evidence until reproduced or cleared by fresh observation.

Do not treat fallback agent counts from an old timed-out status snapshot as authoritative current state.

## Source-of-truth rule

Asana remains the canonical human work, decision, and approval plane. Gas City plus Beads/Dolt are the machine execution and durable-state plane. GitHub stores versioned implementation and approved artifacts. OpenTelemetry/OpenInference provide neutral instrumentation and transport. Phoenix will own AI-observability views and evaluations, not execution truth. None of these systems should silently absorb another system's authority.
